# Both sides

Classroom web app for 馬Sir教室, Form 1, Ch.4 Linear Equations in One Unknown.

Interactive balance scale for Activity 4.1 (“do the same operation on both sides”), a short comparison with transposition of terms（移項）as shorthand only, and Practice with L.H.S. / R.H.S. checking.

Open `index.html` or the GitHub Pages site. Zero install. No student data is collected.
